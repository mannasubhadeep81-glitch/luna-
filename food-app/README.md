# LUMIRA Food — Android MVP

Premium food-delivery customer app foundation built with Jetpack Compose.

Included:
- Restaurant discovery
- Animated restaurant opening experience
- Restaurant menu and food availability
- Add-to-cart micro animation
- Cart and checkout flow
- Order confirmation and tracking screen
- GitHub Actions debug APK build

Next integration layers:
- Real OTP authentication
- Backend/API
- Database
- Real payments
- Live GPS delivery tracking
- Restaurant, delivery-partner and admin apps
